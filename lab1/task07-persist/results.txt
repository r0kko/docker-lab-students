Лабораторная 1. Задание 7. Данные переживают контейнер

Для пересоздания использованы тот же образ mysql:8.0, тот же том mysql-data и прежний пароль, переданный через MYSQL_ROOT_PASSWORD.

$ docker exec mysql-container sh -c 'MYSQL_PWD="$MYSQL_ROOT_PASSWORD" mysql --protocol=TCP --host=127.0.0.1 --connect-timeout=2 --user=root --table --execute="$1"' sh 'CREATE DATABASE testdb;'

$ docker exec mysql-container sh -c 'MYSQL_PWD="$MYSQL_ROOT_PASSWORD" mysql --protocol=TCP --host=127.0.0.1 --connect-timeout=2 --user=root --table --execute="$1"' sh 'SHOW DATABASES;'

| performance_schema |

| testdb             |

$ docker container inspect --format '{{printf "%.12s" .Id}} {{.State.Status}} {{.Config.Image}} {{range .Mounts}}{{.Name}} -> {{.Destination}}{{end}}' mysql-container
