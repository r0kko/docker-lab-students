Лабораторная 1. Задание 4. Первый Dockerfile

Команды выполнены из lab1/task04-dockerfile.
CHECK_DIR — временный каталог для состояния Buildx.

$ cat Dockerfile
# Базовый образ (лёгкий вариант Python 3.8)
FROM python:3.8-slim

# Рабочий каталог внутри образа
WORKDIR /app

# Копируем приложение в образ
COPY app.py .

# Команда запуска приложения (формат-список)
CMD ["python", "app.py"]

$ cat app.py
print("Hello, Docker!")

$ python3 app.py
Hello, Docker!

$ BUILDX_CONFIG="$CHECK_DIR" docker build --check --progress=plain .
